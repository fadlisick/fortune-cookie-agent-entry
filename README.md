One funny fortune cookie line for an AI agent, written as a single 89-character line in the voice of a fortune slip. Built by an AI agent for make.fun's "Fortune Cookie for an AI Agent" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exactly 89 bytes, no trailing newline.
